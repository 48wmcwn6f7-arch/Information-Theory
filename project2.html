Hamming Code

Information Theory — Polina Kuzavkova

Theory

Hamming Code is an error-correcting coding method used to detect and correct errors during the transmission and storage of information.

When data is transmitted through a communication channel, information can be corrupted. For example, one transmitted bit can change its value from 0 to 1 or from 1 to 0.

Hamming Code makes it possible to detect such an error and determine the position of the incorrect bit. The receiver can then correct the error and restore the original information.

How Hamming Code Works

To protect information, special parity bits are added to the original data. These bits are used to check whether the transmitted sequence is correct.

In Hamming Code, parity bits are placed at positions whose numbers are powers of two: 1, 2, 4, 8, and so on.

Each parity bit checks a specific group of positions in the codeword. After receiving the message, the same checks can be performed again to determine whether an error has occurred.

Hamming Code (7,4)

In this project, Hamming Code (7,4) is used. It contains four data bits and three parity bits. The resulting codeword contains seven bits.

Hamming (7,4) = 4 data bits + 3 parity bits

The codeword has the following structure:

p₁ p₂ d₁ p₄ d₂ d₃ d₄

Here, d₁, d₂, d₃, d₄ are data bits, while p₁, p₂, p₄ are parity bits.

Parity Bit Calculation

The parity bits are calculated using the data bits. For Hamming Code (7,4), the following formulas are used:

p₁ = d₁ ⊕ d₂ ⊕ d₄
p₂ = d₁ ⊕ d₃ ⊕ d₄
p₄ = d₂ ⊕ d₃ ⊕ d₄

The symbol ⊕ represents the exclusive OR (XOR) operation. The result is 1 when the number of ones is odd, and 0 when the number of ones is even.

Calculation Example

Consider the following data bits: 1 0 1 1.

The parity bits are calculated as follows:

p₁ = 1 ⊕ 0 ⊕ 1 = 0
p₂ = 1 ⊕ 1 ⊕ 1 = 1
p₄ = 0 ⊕ 1 ⊕ 1 = 0

After inserting the parity bits, we obtain the seven-bit codeword:

0 1 1 0 0 1 1

Therefore, the Hamming Code for the data sequence 1011 is 0110011.
