Shannon Entropy & Hamming Code

Information Theory — Polina Kuzavkova

Theory

Shannon entropy is a measure of the uncertainty or randomness of a source of information.

The greater the uncertainty of a source, the greater its entropy. Entropy is used to quantify the average amount of information contained in a message.

Shannon entropy is measured in bits when the logarithm has base 2.

Shannon Entropy Formula

For a discrete random variable X, Shannon entropy is calculated using the following formula:

H(X) = −Σ p(x) log₂ p(x)

Here, p(x) represents the probability of each possible outcome. The entropy describes the average uncertainty of the information source.

Example

Consider a binary source with two equally probable symbols:

p(0) = 0.5
p(1) = 0.5

The entropy is:

H(X) = −(0.5 log₂ 0.5 + 0.5 log₂ 0.5) = 1 bit

Therefore, a binary source with two equally probable outcomes has an entropy of 1 bit.

Connection with Hamming Code

Shannon entropy describes the amount of uncertainty and information in a source, while Hamming Code is used to protect transmitted information from errors.

These concepts are connected through information transmission. Entropy helps describe the information source, while error-correcting codes help ensure that the information is received correctly.

Information Source → Entropy → Encoding → Transmission → Error Correction
